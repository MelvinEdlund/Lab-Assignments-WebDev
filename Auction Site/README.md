### Auction Site
En fullstack-auktionslösning byggd med React och ASP.NET Web API med SQL Server som databas.  
Applikationen hanterar användare, auktioner och budgivning med JWT-baserad autentisering och rollhantering.

#### Funktioner
- Registrering och inloggning med JWT Authentication
- Skapa och hantera auktioner
- Lägga bud på aktiva auktioner
- Söka efter öppna och avslutade auktioner
- Responsiv design för mobil och desktop
- React Router och Context API för state management och navigering
- ASP.NET Web API med koppling till SQL Server
- Adminfunktioner för att hantera användare och auktioner

Projektet är utvecklat som en fullstack-inlämningsuppgift inom kursen Webbutveckling.
